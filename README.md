# ОСТАТОК / Ostatok

Психологический хоррор на Unity — тестовая сборка 0.9.0.
Psychological horror game made with Unity — test build 0.9.0.

## Скачать / Download

- Архивом: раздел **Releases** → `Ostatok-0.9.0-win64.zip` (проще всего).
- Файлами: папка [`Build/Ostatok`](Build/Ostatok) — запускать `Ostatok.exe`.

The Windows build: **Releases** → `Ostatok-0.9.0-win64.zip`, or the [`Build/Ostatok`](Build/Ostatok) folder.

## Как запустить

1. Распакуйте архив целиком в любую папку (не запускайте прямо из архива).
2. Запустите `Ostatok.exe`.
3. Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае» (сборка не подписана).

**Требования:** Windows 10/11 64-bit, видеокарта с DirectX 11/12.

## Управление / Controls

| Клавиша | Действие |
|---|---|
| WASD, мышь | движение, обзор |
| Shift / Ctrl | бег / присесть |
| E | взаимодействие |
| F | фонарик (в подвале) |
| Tab / J | журнал / доска памяти |
| Space, 1–9 | диалог, варианты ответа |
| Esc | пауза (сохранение, загрузка, настройки) |

Клавиши переназначаются в «Настройки → Управление». Язык (русский/английский) — «Настройки → Язык».

> В игре есть темы травли, насилия, алкоголя, самоповреждения, смерти близкого и пожара.
> Ранняя сборка: временная графика и синтезированный звук.
